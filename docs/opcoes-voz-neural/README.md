# Opções de voz neural (Piper, pt-BR)

Vozes neurais abertas do projeto [Piper](https://huggingface.co/rhasspy/piper-voices) (rhasspy), em
português do Brasil: **Cadu, Edresson, Faber e Jeff**. Cada uma em 3 estilos: normal, mais grave
(e mais calma) e mais aguda (e mais rápida). Nenhuma foi ajustada para imitar pessoa real.

Frase de teste (inventada, do jogo): "Pode parar aí, que essa fuga acabou! Nunca antes um jatinho correu tanto."

| # | Voz | Estilo |
| --- | --- | --- |
| 01 | Cadu | normal |
| 02 | Cadu | grave |
| 03 | Cadu | aguda |
| 04 | Edresson | normal |
| 05 | Edresson | grave |
| 06 | Edresson | aguda |
| 07 | Faber | normal |
| 08 | Faber | grave |
| 09 | Faber | aguda |
| 10 | Jeff | normal |
| 11 | Jeff | grave |
| 12 | Jeff | aguda |

`00-todas.mp3` toca todas em sequência (cada uma começa dizendo o número).
Se escolhidas, as falas do jogo são geradas uma vez em MP3 e soam iguais em qualquer aparelho.
