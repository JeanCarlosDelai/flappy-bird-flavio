# Opções de voz (MBROLA, pt-BR)

Seis vozes masculinas sintetizadas, com estilos diferentes, para escolher uma por personagem.
Nenhuma foi ajustada para imitar pessoa real. Frase de teste (inventada, do jogo):
"Pode parar aí, que essa fuga acabou!"

| Opção | Base | Estilo |
| --- | --- | --- |
| A | MBROLA br1 | normal |
| B | MBROLA br1 | grave e calma |
| C | MBROLA br1 | aguda e rápida |
| D | MBROLA br3 | normal |
| E | MBROLA br3 | grave e pausada |
| F | MBROLA br3 | aguda e acelerada |

`00-todas-as-opcoes.mp3` toca todas em sequência.
